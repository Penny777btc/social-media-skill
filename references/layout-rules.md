# 美丫姐公众号图文排版规范
本文件定义视觉和 Markdown 约定；`scripts/wx_layout.py` 负责将已整理的 Markdown 渲染成公众号可复制的 HTML。用户在本次对话指定的排版参数优先。
## 参数
| 内容类型 | 脚本参数 | 行距 | 段距 | 字距 |
|---|---|---:|---:|---:|
| 干货教程 | `tutorial` | 1.75 | 16px | 1px |
| 测评 | `review` | 1.75 | 16px | 1px |
| 情感故事 | `story` | 2.0 | 24px | 1.5px |
| 资讯 | `news` | 1.6 | 12px | 1px |
- 默认测评类、正文 16px；用户可指定 15px。正文小标题 20px / 17px，辅助文字和图注 14px。
- 标题 `#333333`，正文 `#555555`，辅助 `#999999`，重点色默认 `#E62270`。全文只用这一种重点色；浅色背景取同色 RGB、透明度 0.06–0.08。
- 字体栈：`-apple-system, "PingFang SC", "Microsoft YaHei", "Source Han Sans SC", sans-serif`。最外层正文容器不额外加左右内边距。
## 结构与文字
- 每段通常不超过约 60 个中文字、最多约 5 行。优先在原句号、问号、感叹号处拆段；长单句确实影响阅读时可在自然停顿处分开，但不改措辞。
- 每 300–400 字设置一个视觉锚点，如已有图片、小标题、独立重点句；加粗不要堆叠，同一段最多一处，全文大致每 300 字一处。
- 正文标题最多两级。大标题写在 Markdown 首行供公众号标题栏使用，HTML 正文不重复。可将原有编号功能点提升为小标题；新增标题只概括原文信息。
- 原文中的投票、视频等互动内容若无法直接导入，留有明确占位并列入待确认；不要捏造互动内容。
- 语义不确定、图文可能不符、句子未写完之处不擅自修正。可清理导出 Markdown 对标点的反斜杠转义；若修改了可见文字，在说明中逐条记录。
## Markdown 到 HTML 的约定
| Markdown 写法 | 渲染效果 |
|---|---|
| 第一行 `# 标题` | 只供公众号标题栏使用，HTML 正文不显示 |
| 标题紧接的 `> 导语` | 14px 灰色导语 |
| `##`、`###` | 20px 短色条标题、17px 左色线标题 |
| 普通 `> 引用` | 淡色背景引用框 |
| `> **完整短句**` | 总结卡，全篇最多一个 |
| `**词句**` | 重点色加粗；短标签可用深灰加粗 |
| `- 项目`、`1. 项目` | 圆点列表、编号列表；编号沿用原文或表达真实顺序 |
| `【图片 01：建议内容】` 等整段占位 | 虚线占位框 |
| 行内 `【此句未写完，请补全】` | 重点色提示 |
| `![说明](图片和附件/文件名)` | 原位居中图片；有说明则形成图注 |
原图的 alt 若只是文件名，改成空 alt，避免把随机文件名显示为图注。所有原始图片和 GIF 按原位置保留，宽度不超正文；不要把 GIF 转为静图。只为确有必要的图添加准确图注。外链在 HTML 中以 14px 灰色纯文本显示；长 URL 可独立成段以免撑破排版，并在说明中记录位置调整。
## 品牌贴纸与公众号兼容
- `assets/meiia_open.png` 与 `assets/meiia_end.png` 各出现一次，显示宽 110px、居中、无图注。开篇图位于问候段前；结尾图位于告别段后，若无告别段则放文末。
- HTML 的正文组件使用内联 `style`，以 `section`、`p`、`span`、`strong`、`img` 为主；不要依赖外部字体或样式表、`class`、`id`、`div`、Flex/Grid、定位或原生 `ul/ol`。
- 公众号后台可能清理粘贴样式或图片。交付后应提醒用户保存草稿并用手机预览；缺失图片/GIF 从 ZIP 中的原文件重新上传。
- 当前脚本面向文章常见的标题、段落、列表、引用、图片和网址。遇到表格、代码块或其他复杂 Markdown 时，不要默默丢弃内容；改用能保留该内容的渲染方式并核查结果，或明确列为待处理。
